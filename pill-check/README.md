# Pill Check

Create a clean, modern, and lightning-fast web app interface for a text-based medication and supplement safety analyzer. 

Focus on a minimalist, single-page dashboard layout with the following sections:

1. Top Header: A simple, clean navbar with the app title and a subtle status indicator.

2. Input Section:

   - A prominent, easy-to-use text input box where users can type or paste a list of medications or supplements (e.g., "Aspirin, Ibuprofen").

   - An "Analyze" button.

3. Results Dashboard (Two-Column or Stacked Layout):

   - Detected Items Card:Clean list showing the recognized medicines and their active ingredients/salts.

   - Interaction & Safety Card: A clear status box displaying potential salt interactions or warnings.

   - Alternatives Card: A section suggesting alternative medications or safer formulations.

Design Style: Modern tech startup aesthetic—clean white/light gray background, subtle rounded cards, sharp typography, and fully responsive.
